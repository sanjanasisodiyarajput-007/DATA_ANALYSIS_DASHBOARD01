# 📊 Vrinda Store Sales Data Analysis (Excel Dashboard Project)

### Project Overview
This project analyzes **Vrinda Store’s 2022 sales data** to uncover insights about customer behavior, sales performance, and top-performing categories using **Microsoft Excel**.  
The goal was to transform raw transactional data into a professional, interactive **sales dashboard** for business decision-making.

### Analytical Questions Explored
1. Compare sales and orders using a single chart.  
2. Which month had the highest sales and orders?  
3. Who purchased more — men or women in 2022?  
4. What are the different order statuses?  
5. Which top 10 states contributed most to sales?  
6. Relation between age group and gender based on number of orders?  
7. Which sales channel generated maximum revenue?  
8. What is the highest-selling product category?

### Key Insights
- Total Sales:** ₹ (calculated in Excel)

- Top Month:** **December** recorded the highest sales and order volume.  
- Customer Segment:** *Women customers* contributed more to total sales than men.  
- Order Status:** Majority of orders were successfully *Delivered*.  
- op States:** *Haryana, Punjab, Maharashtra* led in overall sales contribution.  
- Top Category:** *Kurtas* were the highest-selling category.  
- Top Channels:** *Myntra*, *Ajio*, and *Amazon* generated the most sales.
